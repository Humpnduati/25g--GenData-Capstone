# 🏁 F1 GOAT Analysis

## 📌 Overview

This project delivers a **comprehensive, interactive Tableau analysis of Formula 1’s greatest drivers (“GOATs”)**, powered by a **custom Python orchestrator** that builds a historical race dataset (1950–2025).

The orchestrator script (`f1_Api_script.py`) fetches and integrates data from multiple APIs:

* **Ergast API** (historical results from 1950–2023)
* **FastF1** (session/lap/pit data since 2018)
* **OpenF1** (telemetry and lap data since 2022)

It outputs JSON conforming to the [`f1db.schema.json`](./f1db.schema.json) specification, which is then transformed into driver- and season-level summaries for visualization in Tableau dashboards.

## 🚀 Getting Started

### 1. Clone Repository



### 2. Install Python Dependencies

Requires **Python 3.10+**.
Install dependencies with pip:

```bash
pip install aiohttp aiofiles fastf1 jsonschema python-dateutil tqdm
```

### 3. Run the Orchestrator

Fetch full dataset (1950–2025), cache responses, and enrich with OpenF1:

```bash
python f1_Api_script.py \
  --schema f1db.schema.json \
  --out data/f1db.json \
  --from-year 1950 \
  --to-year 2025 \
  --cache-dir cache \
  --resume \
  --openf1
```

Options:

* `--no-fastf1` → disable FastF1 enrichment
* `--openf1` → enable OpenF1 enrichment (recent years only)
* `--resume` → skip already cached responses for faster reruns
* `--cache-dir` → directory to store API responses

### 4. Generate CSVs for Tableau

Transform the JSON output into driver summaries:

```bash
python utils/transform_to_csv.py data/f1db.json
```

This produces:

* `data/drivers_summary.csv`
* `data/driver_year_summary.csv`

### 5. Open Tableau Dashboards

Open `dashboards/F1_GOAT_Analysis.twbx` in Tableau Desktop (2022.1+).
Ensure the data sources point to the generated CSVs in `/data`.

## ⚙️ Key Metrics in Tableau

### Primary Metrics

* **World Championships** → `[total_championship_wins]`
* **Race Wins** → `[total_race_wins]`
* **Podiums** → `[total_podiums]`
* **Poles** → `[total_pole_positions]`

### Derived Metrics

* Win %, Podium %, Pole Rate %
* Career span, Seasons Competed, Efficiency
* **GOAT Score** (composite, adjustable weighting)

```
Championship Score = Championships * 40
Win Score          = Wins * 20
Podium Score       = Podiums * 5
Pole Score         = Poles * 3
Total GOAT Score   = Championship + Win + Podium + Pole
```
